# World and style notes

Context for anyone designing ships, art, missions or mods for this world. Read the relevant file before starting: these notes exist
so that new things fit what is already here, and every number in them is measured from the retail data or marked `PROVISIONAL`.

| File | Use it for |
|---|---|
| [design-language.md](design-language.md) | how ships look: proportions, parts, materials, a checklist for a new ship |
| [factions.md](factions.md) | what the Navy, Pirates, Procyon and civilians field and how to tell them apart |
| [ships.md](ships.md) | the retail ship catalogue with points, speed, HP and guns, to place a new ship |
| [setting.md](setting.md) | what the world is, what the game shows, what we do not yet know |
| [../remaster-style.md](../remaster-style.md) | the lighting and effects direction of the remaster mod |

These are guidance, not rules. A mod may look like anything it likes; these notes describe the retail look so that anyone who wants
a ship to sit beside the originals knows how. They are written in our own words from the retail data and the film's public
direction: never copy text, art or names of assets from the game or the film into them (see `AGENTS.md`, hard rules).
